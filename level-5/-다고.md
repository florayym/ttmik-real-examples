# -(ㄴ/는)다고 — 间接引用（陈述）

> TTMIK Level 5 Lesson 17
> 📖 语法核心：转述他人话语/想法时用 -다고，名词谓语为 -(이)라고。

## 26학번 지원이요 15화

> 来源：TJ转述前女友的事；시크릿가든选角传闻

### 例句 1
**原句：** …중학교 때 하지원 씨랑 같은 반이라고 그랬어.
**场景：** TJ转述"听说她初中和하지원同班"。
**拆解：**
- 반（班）+ **이라고**（说是…）+ 그랬어（这么说过）
**讲解：** 间接引用：动/形 + 다고，名词 + (이)라고。同款：원래 시크릿 가든 남주인공이 장혁 님이었다고 / 길라임 씨와 만날 뻔했다고? / 내가 온다(고) 그랬잖아。

## ENA《클라이맥스》제작발표회

> 来源：ENA 드라마《클라이맥스》제작발표회 포토타임 + 질의응답（주지훈·하지원·나나·오정세·이지원 감독, 진행 박경림）

### 例句 1
**原句：** 정우 형한테 "형 내 거 시청률 잘 나왔으면 좋겠다" 그래서 / 하고 싶**다고** 생각
**场景：** 주지훈转述自己曾对前辈说过、或心里想过的话。
**拆解：**
- 하고 싶（想做）+ 다고（间接引用标记）+ 생각（想/认为）
**讲解：** -다고 用于转述自己或他人说过/想过的话，口语中也常配合 그래서/그러다 直接复述原话再加总结。

## 성시경의 만날텐데 × 하지원

> 来源：YouTube《성시경의 만날텐데》하지원 편（《클라이맥스》宣传期对谈，성시경·하지원；自动字幕）

### 例句 1
**原句：** 이게 구독자 특가가 있**다고** 하는데 링크에 걸어 놓을 테니까 확인해 보시고.
**场景：** 广告环节：厂家说有订阅者特价。
**拆解：**
- 있다 + -다고 하다 → 있다고 하는데
**讲解：** 教科书标准形。信息来源是别人，用 -다고 하다 表明"这是（官方）说的"。

### 例句 2
**原句：** 오늘은 와인이 드시고 싶**다고** 그래서 … 화이트 와인에 잘 어울리는 음식들 준비했고
**场景：** 성시경解释菜单：因为하지원事先说想喝葡萄酒。
**拆解：**
- 드시고 싶다 + -다고 + 그러다 + -어서 → 싶다고 그래서
**讲解：** 引用直接充当理由："因为（她）说想喝……，所以准备了……"。그러다 是口语里最常用的说话动词。

### 例句 3
**原句：** 사실 사람이 그러면 안 되는데 하지원 씨 나온**다고** 좀 신경을 썼어요.
**场景：** 성시경承认因为하지원要来，备菜特别用心，被工作人员说区别对待。（字幕 화전 씨 应为 하지원 씨）
**拆解：**
- 나오다 + -ㄴ다고（后面没有 하다）
**讲解：** -다고 单独连接后句时表示理由："听说/想到……，所以……"。比 -아/어서 多一层"因为有这么一回事"的转述色彩。

### 例句 4
**原句：** 너무 가고 싶다 그랬는데 / 흠잡을 데가 없다 그랬더니
**场景：** 转述同剧演员说"特别想来"；성시경说自己评价演员们"无可挑剔"。
**拆解：**
- 가고 싶다 + [고 脱落] + 그러다 → 싶다 그랬는데
- 完整形：가고 싶다**고** 그랬는데
**讲解：** 真实口语中 -고 常被吞掉，形成"裸引用"。听力上要适应，不然会以为句子断了。

### 例句 5
**原句：** 저는 뭘 하나라도 좋아야 된**다고** 생각하거든요. / 난 어쨌건 하는 사람이 행복한 작품이 중요하**다고** 생각하거든요.
**场景：** 성시경谈看剧标准和选作品的看法。
**拆解：**
- 좋아야 되다 / 중요하다 + -다고 생각하다
**讲解：** -다고 생각하다 = 明确表态"我认为……"，比 -것 같다 立场更清楚。

### 例句 6
**原句：** 만드는 과정에서 되게 재밌**다고** 해야 될까요? / 되게 털털하고 편하**다** 그래야 되나?
**场景：** 하지원描述表演的乐趣、描述차주영的性格时，一边找词一边说。
**拆解：**
- 재밌다 + -다고 하다 + -아야 되다 + -ㄹ까요?
- 편하다 + [고 脱落] + 그러다 + -아야 되나?
**讲解：** -다고 해야 되나/될까요 = "该说是……吗"，给自己的措辞打个软垫，口语中非常常用。

### 例句 7
**原句：** 오늘 후시가 12시에 있**다는** 거야. / 본인도 하신**다는** 얘기야?
**场景：** 성시경转述同剧演员说当天有配音；하지원说喜欢自制意面，성시경追问"你的意思是自己也会做？"
**拆解：**
- 있다 + -다는（引用定语）+ 거야
- 하시다 + -ㄴ다는 + 얘기 + -야?
**讲解：** -다는 거야 = "说是……（你猜怎么着）"，带转折感；-다는 얘기예요? = "你的意思是……？"，用来确认对方话里的意思，谈话节目几乎每集都有。

### 例句 8
**原句：** 걔가 이제 늘어난**다라고** 계속 이제 신호를 얘한테 보내는 거죠.
**场景：** 하지원讲拉伸：不断向肌肉发送"你在变长"的信号。
**拆解：**
- 늘어나다 + -ㄴ다（叙述体，L5 L16）+ 라고
- 规范形：늘어난다**고**
**讲解：** -ㄴ다 后再接 라고 是口语里的"双重标记"，书写不建议模仿，听懂即可。

### 例句 9
**原句：** 와인을 드신**다서** 제가 양식은 잘 못 하는데 오늘 열심히 한번 해 봤습니다.
**场景：** 성시경对하지원说：听说您要喝葡萄酒，虽然我不太会做西餐，今天还是努力做了。
**拆解：**
- 드시다 + -ㄴ다 + [고 해] + -서 → 드신다서
- 完整形：드신다**고 해서**
**讲解：** -다고 해서（因为听说）在快语速中整段吞掉，只剩 -다서。同期还有 이번에 나오신다서（听说你这次要上节目）。
