# N+(이)라고 (하다) — 称…为…/叫做…

> TTMIK Level 5 Lesson 10
> 📖 语法核心：名词的引用、命名，"把…叫做/说成…"。

## ENA《클라이맥스》제작발표회

> 来源：ENA 드라마《클라이맥스》제작발표회 포토타임 + 질의응답（주지훈·하지원·나나·오정세·이지원 감독, 진행 박경림）

### 例句 1
**原句：** 시나리오 상에서 **도베르만이라고** 표현을 했는데
**场景：** 감독解释为何选주지훈 —— 剧本里把这个角色形容成"杜宾犬"。
**拆解：**
- 도베르만（杜宾犬，外来词）+ 이라고（叫做/称为）+ 표현을 하다（表达）
**讲解：** N+(이)라고 하다 = "把…叫做/说成…"。缩约成 -(이)라는 时变定语：「번지점프를 하다**라는** 작품」(叫《纵身一跳》的作品)，是后面 L7「N+(이)라는 것」的基础砖块。

## 성시경의 만날텐데 × 하지원

> 来源：YouTube《성시경의 만날텐데》하지원 편（《클라이맥스》宣传期对谈，성시경·하지원；自动字幕）

### 例句 1
**原句：** 원래 저는 모든 건 의외성이 제일 매력**이라고** 생각해요.
**场景：** 성시경阐述"意外性/反差感最有魅力"。
**拆解：**
- 매력（魅力，汉字词）+ 이라고（有收音接 이라고）+ 생각하다
**讲解：** 把名词句「의외성이 제일 매력이다」装进 -(이)라고，后接认知动词。中文"我认为……是……"不需要任何标记，韩语必须有 라고 这个"引号"。同期：그 주인공의 마음이 돼서 그렇게 하는 거**라고** 생각해（것/거 + 라고 생각하다）。

### 例句 2
**原句：** 요즘에 주변에 다 하지원 씨 지금 리즈**라고** 막 얘기를 많이 하더라고요.
**场景：** 성시경说身边的人都在讲하지원现在处于颜值巅峰期。
**拆解：**
- 리즈（全盛期，网络用语）+ 라고（无收音接 라고）+ 얘기를 하다 + -더라고요（L7 L12）
**讲解：** 引用的内容可以只是一个词。引用 + -더라고요 = "（我亲耳听到）大家都说……"。

### 例句 3
**原句：** 근데 마음에 들어서 "하겠습니다"**라고** 했고.
**场景：** 성시경讲接广告的经过：用了两个月很满意，就回复说"我接"。
**拆解：**
- 하겠습니다（-겠 意志 + 합쇼체）整句 + 라고 + 했다
**讲解：** 直接引用的规范形：原话连敬语语尾一起照搬，后接 라고 하다。相当于中文加引号。

### 例句 4
**原句：** 이게 내가 어제 "부를 텐데" **했을 때** 얘기했던 거랑 비슷한 거야. / 아, 여기서 우회전해야지 **하고** 차선을 딱 바꾸는 순간
**场景：** 성시경提到自己前一天录的《부를 텐데》；又举例开车时心想"啊，该右转了"，一变道感动就没了。（字幕 왜전해야지 推测为 우회전해야지）
**拆解：**
- 직접 인용 + 하다（说）→ 했을 때
- 内心话 + 하고（心想着）
**讲解：** 口语里 라고 하다 常简化成只剩 하다。"想"和"说"共用同一套引用装置：「……해야지 하고」= "心里想着'该……了'"，与中文"心想：……"意外一致。同期还有把内心话直接加宾格：내가 연기를 이렇게 해야지**를** 100% 만들고 가지 않는(다)。

### 例句 5
**原句：** 클라이맥스**라는** (드라마) / 지영이**라는** 사람 자체 / 나**라는** 사람에 대해 고민을 하기 시작한 거예요.
**场景：** 介绍剧名；하지원谈차주영"这个人本身"（字幕 지영 应为 주영）；하지원谈开始思考"我这个人"。
**拆解：**
- N + (이)라고 하는 → (이)라는 + N
**讲解：** "叫做 N 的……"。나라는 사람 = "我这个人"，用引用定语给"我"加框，带有审视自己的距离感。

### 例句 6
**原句：** "어, 그럼 이제부터 행복하겠네"**라는** 얘기를 했는데
**场景：** 성시경转述自己当时对차주영说的话。
**拆解：**
- 행복하겠네（-겠 推测 + -네 感叹）整句 + 라는 + 얘기
**讲解：** 直接引用也可以走 -라는 + 名词 的定语化路线，原话的感叹语尾原样保留。

### 例句 7
**原句：** 가련하고 좀 뭐**라** 그러나, 성공에 굶주려 있거니까
**场景：** 성시경形容하지원的角色时一时找不到词。
**拆解：**
- 뭐（什么）+ 라（고）+ 그러다 + -나 → 뭐라 그러나 ≈ 뭐라고 하나
**讲解：** "该怎么说呢"，口语思考时的填充语，本质是名词引用 -(이)라고。
