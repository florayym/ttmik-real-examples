# -ㄴ/는/ㄹ 것 같다 — 我觉得/好像……

> TTMIK Level 4 Lesson 27
> 📖 语法核心：推测或委婉判断。全片使用最频繁的语法。

---

## 경희대 축제 vlog

> 来源：YouTube 경희대학교 응원단 축제 vlog

### 例句 1（未来推测）
**原句：** 망칠 거 같아.
**场景：** 지원担心自己会搞砸大家的演出。

**拆解：**
- 망치다（搞砸）→ 망칠 거 같아（觉得会搞砸）

### 例句 2（现在判断）
**原句：** 케어를 열심히 해야 되는 거 같아요.
**场景：** 说头发必须像皮肤一样认真护理。

**拆解：**
- 해야 되다 → 해야 되는 거 같아요（觉得必须……）

### 例句 3（过去推测）
**原句：** 다 구워진 거 같아요.
**场景：** 问妆是不是"烤"好了。

**拆解：**
- 구워지다（被烤）→ 구워진 거 같아요（觉得已经烤好了）

**讲解：**
| 时态 | 结构 | 例句 |
|---|---|---|
| 未来推测 | -ㄹ 거 같다 | 망칠 거 같아 |
| 现在判断 | -는 거 같다 | 해야 되는 거 같아요 |
| 过去推测 | -(으)ㄴ 거 같다 | 구워진 거 같아요 |

韩语用 것 같다 作为委婉默认表达，比直接断言更柔和、更礼貌。

## 26학번 지원이요 15화

> 来源：导演给走位建议；调侃"找交集"

### 例句 1
**原句：** 처음에 워킹할 때 조금 더 시원하게 나오는 게 좋을 것 같아요.
**场景：** 导演建议开场走位再利落一点。
**拆解：**
- 좋（好）+ **을 것 같**（我觉得会…）+ 아요
**讲解：** 用 -것 같다 提建议显得不强加。同款：너무 실일 것 같은데（"感觉会很亏"）。冠形形按时态选 -ㄴ/는/(으)ㄹ。

## ENA《클라이맥스》제작발표회

> 来源：ENA 드라마《클라이맥스》제작발표회 포토타임 + 질의응답（주지훈·하지원·나나·오정세·이지원 감독, 진행 박경림）

### 例句 1
**原句：** 지금 솔직히 말해서 약간 **토할 것 같은** 기분이거든요
**场景：** 이지원감독被问首次拍剧的感受，说紧张到想吐。
**拆解：**
- 토하（呕吐）+ ㄹ 것 같（未来定语 + 것 같다）
**讲解：** -(으)ㄹ 것 같다 表"快要…的样子/感觉好像要…"。全场这个结构出现十几次：「연기 변신이 될 것 같은데요」「필모의 클라이맥스가 되지 않을까 싶은데요」。韩语下结论极少说 -다고 생각하다（太硬太武断），默认走 -것 같다 的"看起来…"，这是社会性软化机制。

## 성시경의 만날텐데 × 하지원

> 来源：YouTube《성시경의 만날텐데》하지원 편（《클라이맥스》宣传期对谈，성시경·하지원；自动字幕）

### 例句 1
**原句：** 저를 지우는 작업이 전 더 어려웠던 **거 같아요**.
**场景：** 하지원谈为角色"抹掉하지원本人痕迹"的过程。
**拆解：**
- 어렵다 + -었- + -던（回想定语）+ 거（것）+ 같아요
**讲解：** 韩语表达主观感受几乎默认套 -것 같다，避免断言。것 口语弱化为 거。

### 例句 2
**原句：** 지금 드라마 클라이맥스를 소개를 해 주시면 좋을 **것 같아요**.
**场景：** 성시경请하지원介绍新剧。
**拆解：**
- 해 주시다 + -면 + 좋다 + -을 것 같다
**讲解：** -면 좋을 것 같아요 = 委婉请求"您要是能……就好了"，比直接命令礼貌得多。

### 例句 3
**原句：** 되게 좋으셨을 **것 같아요**.
**场景：** 성시경推测演员们彼此配合得很愉快。
**拆解：**
- 좋다 + -으시- + -었을（过去推测）+ 것 같다
**讲解：** 三个例句恰好覆盖 -던 / -ㄹ / -었을 三种时态的 것 같다。
