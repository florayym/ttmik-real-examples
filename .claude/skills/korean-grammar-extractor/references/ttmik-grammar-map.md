## Level 1
| 课 | 类型 | 句型 / 主题 | 教什么 |
|----|------|-------------|--------|
| L1 | 表达 | 안녕하세요, 감사합니다 | 最基本的问候与致谢；初识敬语体结尾 |
| L2 | 表达 | 네, 아니요, 네? | 是 / 不是 / 没听清时反问「네?」 |
| L3 | 表达 | 안녕히 계세요, 안녕히 가세요 | 告别：离开者说 계세요（请留步），留下者说 가세요（慢走）；半语 안녕 |
| L4 | 表达 | 죄송합니다, 저기요 | 道歉，以及叫住别人、引起注意的说法 |
| L5 | 语法 | N + 이에요/예요 | 系词「是」：有收音接 이에요，无收音接 예요 |
| L6 | 语法 | 이거 …, 이거 뭐예요? | 用 이거 + 이에요/예요 指认物品；「这是什么？」 |
| L7 | 语法 | 이/그/저 + N, 이것/그것/저것（거） | 指示词：이 近说话人、그 近听话人或前文已提、저 远离双方；것 口语作 거 |
| L8 | 语法 | N + 이/가 아니에요 | 系词否定「不是…」 |
| L9 | 语法 | 은/는, 이/가 | 主题助词 vs 主格助词：은/는 提出话题、表对比；이/가 标主语、引出新信息 |
| L10 | 语法 | 있어요 / 없어요 | 「有 / 没有」「在 / 不在」 |
| L11 | 语法 | N + 주세요 | 「请给我…」 |
| L12 | 表达 | 맛있어요, 잘 먹겠습니다 | 好吃 / 难吃；饭前「잘 먹겠습니다」、饭后「잘 먹었습니다」 |
| L13 | 语法 | V-고 싶어요 | 「想做…」 |
| L14 | 语法 | 뭐 -고 싶어요? | 疑问词 뭐 + -고 싶다：「你想做什么？」 |
| L15 | 词汇 | 일, 이, 삼, 사… | 汉字数词：日期、金额、电话号码、分钟等 |
| L16 | 语法 | -아/어/여요 | 现在时 해요体：词干末元音 ㅏ/ㅗ → -아요，其他 → -어요，하다 → 해요 |
| L17 | 语法 | -았/었/였어요 | 过去时：词干末元音 ㅏ/ㅗ → -았어요，其他 → -었어요，하다 → 했어요 |
| L18 | 语法 | 어디, -에, -에서 | 地点助词：에 表存在位置 / 移动目的地，에서 表动作发生场所 |
| L19 | 语法 | 언제 | 疑问词「什么时候」；时间名词 + 에 |
| L20 | 词汇 | 하나, 둘, 셋, 넷… | 固有数词：数个数、年龄、钟点；接量词时 하나→한、둘→두 等变形 |
| L21 | 语法 | 안 + V, V-지 않다 | 否定：短否定 안 vs 长否定 -지 않다 |
| L22 | 语法 | N + 하다 | 하다 动词：名词 + 하다 构成动词（공부하다、일하다）及其活用 해요 / 했어요 |
| L23 | 语法 | 누구, 누가 | 疑问词「谁」：누구 + 이/가 → 누가 |
| L24 | 语法 | 왜, 어떻게 | 疑问词「为什么」「怎么 / 如何」 |
| L25 | 语法 | -에서/부터 -까지 | 「从…到…」：地点用 에서~까지，时间用 부터~까지 |
| L26 | 复习 | Essential Review | Level 1 总复习 |

## Level 2
| 课 | 类型 | 句型 / 主题 | 教什么 |
|----|------|-------------|--------|
| L1 | 语法 | -(으)ㄹ 거예요 | 将来时：「将要…、打算…」 |
| L2 | 语法 | 을/를 | 宾格助词：有收音 을，无收音 를；口语常省略 |
| L3 | 语法 | 그리고, 그래서 | 连接副词：그리고「而且 / 然后」，그래서「所以」 |
| L4 | 语法 | -하고, -(이)랑 | 「和 / 跟」：并列名词或表同伴；(이)랑 更口语 |
| L5 | 词汇 | 요일 | 星期：월요일~일요일（月火水木金土日） |
| L6 | 语法 | 그렇지만, 그런데 | 「但是」：그렇지만 纯转折；그런데 转折兼转换话题 / 铺垫背景 |
| L7 | 语法 | 한테, 한테서 | 「给 / 对某人」与「从某人那里」 |
| L8 | 词汇 | 시간 말하기 | 报时：「시」用固有数词，「분」用汉字数词；오전 / 오후 |
| L9 | 词汇 | 개, 명 | 量词：固有数词 + 개（个）/ 명（人）等 |
| L10 | 语法 | -고 있어요 | 现在进行时「正在…」 |
| L11 | 表达 | 자기소개 | 自我介绍常用句：名字、年龄、职业、住处等 |
| L12 | 词汇 | 날짜 | 日期：년 / 월 / 일 用汉字数词；6월→유월、10월→시월 |
| L13 | 语法 | -도（1） | 「也」：-도 替换 은/는/이/가/을/를 |
| L14 | 语法 | -도（2） | -도 接在动词上：先变名词形 -기，再说 -기도 하다（보기도 하다、먹기도 하다） |
| L15 | 语法 | -만 | 「只」：N + -만；动词先变名词形 -기，再说 -기만 하다 |
| L16 | 语法 | 아주, 조금, 진짜, 별로, 전혀 | 程度副词：很、有点、真的、不怎么（+否定）、完全不（+否定） |
| L17 | 语法 | -(으)ㄹ 수 있다/없다 | 「能 / 不能」（能力、可能性） |
| L18 | 语法 | 잘하다 / 못하다 | 「擅长 / 不擅长」；잘 + V、못 + V |
| L19 | 语法 | -는 것 | 动词名词化「做…这件事」；口语 -는 거 |
| L20 | 语法 | -아/어/여야 되다/하다 | 「必须 / 应该」 |
| L21 | 语法 | -보다 (더) | 比较「比…更…」 |
| L22 | 语法 | 좋다 vs 좋아하다 | 形容词 N이/가 좋다 vs 动词 N을/를 좋아하다 |
| L23 | 语法 | 만약, -(으)면 | 条件「如果…」；만약 加强假设语气 |
| L24 | 语法 | 아직, 벌써 | 「还 / 仍然（+否定：还没）」与「已经」 |
| L25 | 语法 | 누군가, 뭔가, 어딘가, 언젠가 | 不定代词：疑问词 + -ㄴ가 →「某人 / 某物 / 某处 / 某时」 |
| L26 | 语法 | -(으)세요 | 敬语命令「请…」 |
| L27 | 语法 | -아/어/여 주세요 | 「请为我做…」 |
| L28 | 语法 | -(으)로 | 手段 / 方式 / 方向「用、乘、往」；ㄹ收音后接 로 |
| L29 | 语法 | 더, 다 | 「更、再」与「全部、都」 |
| L30 | 语法 | -지 마세요 | 禁止「请不要…」 |
| L31 | 复习 | Essential Review | Level 2 总复习 |

## Level 3
| 课 | 类型 | 句型 / 主题 | 教什么 |
|----|------|-------------|--------|
| L1 | 表达 | 너무 | 「太、过于」，口语中也常作「非常」 |
| L2 | 语法 | -고 | 连接动词 / 句子：「…而且 / 然后…」 |
| L3 | 语法 | 앞/뒤/위/밑/옆 + 에 | 方位：前、后、上、下、旁边 |
| L4 | 语法 | -(으)ㄹ까요? | 「我们…好吗？」征求意见；也表「会不会…呢」的自问推测 |
| L5 | 语法 | 쯤, 약, 정도 | 「大约」：쯤 / 정도 后置，약 前置 |
| L6 | 语法 | -(으)ㄹ 거예요 vs -(으)ㄹ게요 | 将来时对比：거예요 陈述计划 / 推测，ㄹ게요 是对听者的承诺、意愿表态 |
| L7 | 语法 | -아/어/여서 | 连接：原因「因为…所以」与先后「…之后（接着）…」 |
| L8 | 语法 | N + 같아요 | 名词 + 같다：「像…、好像是…」 |
| L9 | 语法 | -(으)ㄴ/는 것 같아요 | 动词 / 形容词 + 것 같다：「好像…、我觉得…」 |
| L10 | 语法 | -기 전에 | 「在…之前」 |
| L11 | 活用 | ㅂ 불규칙 | ㅂ 不规则：ㅂ 遇元音变 우 / 오（춥다→추워요、돕다→도와요） |
| L12 | 语法 | 그래도 | 「即便如此、但还是」 |
| L13 | 语法 | 形容词 + -(으)ㄴ + N | 形容词作定语修饰名词（예쁜 꽃） |
| L14 | 语法 | 动词 + -는 + N | 动词现在时定语「…的 N」（노래하는 사람、좋아하는 책）；官方课名写作 -는/(으)ㄴ/(으)ㄹ + 명사，但讲义只讲 -는：过去时定语见 L4-26，将来时定语见 L4-25 |
| L15 | 语法 | 그러면, 그럼 | 「那么、那样的话」 |
| L16 | 语法 | -아/어/여요（청유형） | 해요体同形表「我们一起…吧」，靠语境区分 |
| L17 | 语法 | 위하다, 위해(서) | 「为了…」：N을/를 위해서、V-기 위해서 |
| L18 | 语法 | 밖에 + 否定 | 「只有…（而已）」，强调少、常带不满（与 -만 对比） |
| L19 | 语法 | -(으)ㄴ 다음에 | 「…之后」 |
| L20 | 语法 | -아/어/여도 | 「即使…也」 |
| L21 | 语法 | -는/(으)ㄴ데 | 连接语尾：铺垫背景、转折、委婉 |
| L22 | 语法 | -(으)ㄹ 수도 있다 | 「也有可能…、说不定会…」 |
| L23 | 构词 | 학(學) | 汉字词根「学」：학교、학생、학원、유학 |
| L24 | 活用 | 르 불규칙 | 르 不规则：모르다→몰라요、빠르다→빨라요 |
| L25 | 语法 | -네요 | 感叹 / 当场发现「…呢！」 |
| L26 | 活用 | ㄷ 불규칙 | ㄷ 不规则：ㄷ 遇元音变 ㄹ（듣다→들어요、걷다→걸어요） |
| L27 | 语法 | 반말 / 존댓말 | 敬语体与半语：去掉 -요 的 반말，以及对谁用哪种 |
| L28 | 语法 | -자 | 半语的「…吧」（共动） |
| L29 | 活用 | ㅅ 불규칙 | ㅅ 不规则：ㅅ 遇元音脱落（낫다→나아요、짓다→지어요） |
| L30 | 构词 | 실(室) | 汉字词根「室」：교실、화장실、사무실 |
| L31 | 复习 | Essential Review | Level 3 总复习 |

## Level 4
| 课 | 类型 | 句型 / 主题 | 教什么 |
|----|------|-------------|--------|
| L1 | 语法 | -(으)면 -(으)ㄹ수록 | 「越…越…」 |
| L2 | 语法 | -(으)ㄹ래요(?) | 问对方意愿「你要…吗？」/ 表自己意愿「我要…」（口语、亲近） |
| L3 | 语法 | -(으)ㄹ 리가 없다 | 「不可能…、哪会…」 |
| L4 | 语法 | -지요 / -죠 | 确认、求同「…吧？/ …对吧」，也用于委婉陈述 |
| L5 | 表达 | 당신 | 「당신」的用法与限制：韩语很少直接说「你」，多用名字 / 称谓 |
| L6 | 构词 | 동(動) | 汉字词根「动」：운동、동물、동작、활동 |
| L7 | 表达 | 괜찮아요 | 괜찮다 的多种用法：没关系、还不错、不用了（婉拒） |
| L8 | 语法 | -아/어/여도 되다 | 许可「可以…」；안 + V-아/어/여도 되다「不…也可以」 |
| L9 | 语法 | -(으)면 안 되다 | 禁止「不可以…、不应该…」 |
| L10 | 语法 | 사이에(서), 중에(서) | 「在…之间 / 之中」 |
| L11 | 语法 | 아무나, 아무도, 아무거나, 아무것도 | 「谁都 / 谁也不 / 什么都行 / 什么都不」 |
| L12 | 语法 | -아/어/여 보다 | 尝试「…看看」；过去式表经历 |
| L13 | 构词 | 불(不) | 汉字词根「不」：불안、불편、불만；有时读 부（부정확、부주의） |
| L14 | 语法 | 가끔, 자주, 별로, 맨날, 항상 | 频率副词：偶尔、经常、不太（+否定）、天天、总是 |
| L15 | 语法 | 아무（2） | 아무 + N + -(이)나 / -도：아무 데나、아무 때나、아무 말도 |
| L16 | 书写 | 띄어쓰기（1） | 分写规则基础：助词连写、词与词分写 |
| L17 | 书写 | 축약형（1）主格助词 | 口语缩略：나는→난、저는→전、이것이→이게 |
| L18 | 语法 | 제일, 가장 | 最高级「最…」：제일 是汉字词、가장 是固有词，可以互换 |
| L19 | 语法 | 덜 | 「没那么…、没完全…」（덜 익었다） |
| L20 | 操练 | Sentence Building Drill #1 | 以基本句为核心，叠加本级前段语法造长句 |
| L21 | 书写 | 띄어쓰기（2） | 分写进阶：依存名词（것、수、때）与单位名词的分写 |
| L22 | 构词 | 장(場) | 汉字词根「场」：시장、주차장、운동장、장소 |
| L23 | 书写 | 축약형（2） | 更多缩略：것은→건、것을→걸 等 |
| L24 | 语法 | 훨씬 | 「…得多」：强调比较差距 |
| L25 | 语法 | -(으)ㄹ + N | 将来时定语（할 것、할 일） |
| L26 | 语法 | -(으)ㄴ + N | 过去时定语（한 것、먹은 음식） |
| L27 | 语法 | -(으)ㄴ/는/(으)ㄹ 것 같다 | 「好像…、我觉得…」按过去 / 现在 / 将来的完整推测用法 |
| L28 | 语法 | 形容词 + -아/어/여지다 | 「变得…」状态变化 |
| L29 | 语法 | -게 되다 | 「（结果）变成…、渐渐 / 终于…」非主观意愿造成的变化 |
| L30 | 操练 | Sentence Building Drill #2 | 造长句练习，综合本级后段语法 |
| L31 | 复习 | Essential Review | Level 4 总复习 |

## Level 5
| 课 | 类型 | 句型 / 主题 | 教什么 |
|----|------|-------------|--------|
| L1 | 语法 | -(으)ㄹ 뻔했다 | 「差点儿就…」 |
| L2 | 语法 | -(으)시- | 主体敬语 -(으)시- 与 께서；特殊形 드시다（먹다 / 마시다）、말씀하시다、식사하시다；-셔요 → -세요 |
| L3 | 表达 | 수고 | 수고하셨습니다 / 수고하세요「辛苦了」的用法与对谁能说 |
| L4 | 语法 | -나 보다 | 「看样子…」基于观察的推测（动词） |
| L5 | 语法 | -(으)ㄴ가 보다 | 同上，用于形容词 / 이다 |
| L6 | 构词 | 문(文) | 汉字词根「文」：문화、문장、문법、문자 |
| L7 | 语法 | -자마자 | 「一…就…」 |
| L8 | 语法 | -(으)려고 하다 | 「打算…」/「快要…、正要…」 |
| L9 | 语法 | -다가 | 「做着…（中途）转而…」 |
| L10 | 语法 | N + -(이)라고 (하다) | 引用名词：「说是…、叫做…」 |
| L11 | 操练 | Sentence Building Drill 3 | 造长句练习，综合本级前段语法 |
| L12 | 语法 | -(이)라는 + N | 「叫做…的 N、所谓…的 N」 |
| L13 | 构词 | 회(會) | 汉字词根「会」：회사、회의、사회、회원 |
| L14 | 语法 | -(으)니까 | 「因为…（所以）」主观理由，后句可接命令 / 共动；也表「一…发现…」 |
| L15 | 语法 | -(이)라도 | 「哪怕…也好」退而求其次 |
| L16 | 语法 | -(ㄴ/는)다 | 叙述体现在时（日记、新闻、书面、自言自语） |
