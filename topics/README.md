# 专题导航 — 跨级别语法专题总览

> 同一个语法家族在 TTMIK 里往往分散在好几个 Level。专题页把它们按一条主线串起来，链接到各课文件；例句只存在各课文件里，专题页不重复。

## 两种专题

- **形态型**：从"听到的形态"出发——这个形态是怎么由更基本的部分组合、缩略出来的。适合听力和拆句。
- **意义型**：从"想表达的意思"出发——同一个意思有哪几种说法、各自的限制是什么，附中文对照。适合口语和写作。

## 读表说明（各专题页通用）

- **课号** `L5-17` = TTMIK Level 5 Lesson 17。以讲义 PDF 的页眉和 TTMIK 官方课程目录为准；专题页里每一个课号都对照讲义原文核实过：该课确实讲了这一格写的形态。
- **有例句**：这个形态在本 repo 里已有真实媒体例句，点击进入例句所在文件。
- **待采集**：TTMIK 有这一课，但 repo 里还没有这个形态的例句。
- **附带出现**：这个形态还没有收进对应的课文件，但别的文件的例句里已经出现过（注明文件和原句片段），可以直接补录。
- **—**：TTMIK 没有讲这个组合。格子里不写任何形态，以免臆造；repo 若已从媒体采到，单独列在「课程外」表里。
- **原文回指**：该课讲义里明确提到的更早课号（"In Level X Lesson Y…"或"上一课"），即 TTMIK 自己标出的递进关系；— 表示讲义没有回指。

标注一律用文字而不用符号：不必查图例就能读懂，也可以直接搜索「待采集」把所有专题的采集清单一次找出来。

## 课号说明

- 课号以讲义 PDF 的页眉和 TTMIK 官方课程目录为准，和 `.claude/skills/korean-grammar-extractor/references/ttmik-grammar-map.md` 一致。
- 讲义正文里有几处回指写错了，专题页一律不照抄：L5-29 把 -다고 那一课写成「Level 5 Lesson 16」（实为 L5-17；L7-17、L10-14 都写作 Lesson 17）；L8-6 把 무슨 말이에요? 那一课写成「Level 6 Lesson 2」（实为 L6-12）；L6-2 的讲义页眉误印为「LEVEL 6 LESSON 12」。
- TTMIK 没有单独成课的形态不给课号：只有在 repo 已经采到真实例句时，才列进各页的「课程外」表，并注明"TTMIK 无专课"。
