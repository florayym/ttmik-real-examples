## 形态拆解（讲义原文的拆法）

- 그러면 = 그렇다 + -면（L3-15）；이렇다 / 그렇다 / 저렇다 + -면 时 ㅎ 脱落：이러면 / 그러면 / 저러면（L4-23）
- -(으)면 안 되다 = -(으)면「如果」+ 안 되다「行不通」（L4-9）
- -(으)면 좋겠어요 = -(으)면「如果」+ 좋다 + -겠-「（推测）会…」（L8-8）
- -아/어/여야 되다 = -아/어/여야「只有在…的时候」+ 되다「行得通」（L2-20）
- 얼마나 -(으)면 = 얼마나「多少」+ -(으)면「如果」（L10-27）
- L7-27 给了三种「只要」的直译：-기만 하면「如果只是…」、-(느)ㄴ 한「在…的范围内」、-지만 않으면「只要不…」
