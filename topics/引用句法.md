## 矩阵二：-다고 하- / -라고 하- 再接语尾（融合形）

这些形态都是"引用 + 另一个语尾"缩出来的，讲义自己也是这么拆的：-다던데 = -다고 하던데（L7-18），-다면서 = -다 + -다고 말하면서（L9-24），-다니 = -다고 하니（L10-14），-다기보다 = -다고 하기보다（L10-17）。疑问句一列 TTMIK 全部没有讲，表中省略。

## 口语里的完整形 → 简化形（repo 例证）

引用标记在真实口语里会一路简化，听力上要逐级适应：

- 陈述：**-다고 하다 / 그러다** → 口语省掉 고：**-다 그러다**（「너무 가고 싶다 그랬는데」）；缩略成 **-대(요)**（L7-17）；**-다고 해서** → **-다서**（「와인을 드신다서」）
- 名词：**-(이)라고 하는** → **-(이)라는**（L5-12 讲义原文）；**-(이)라는 것은** → **-(이)란**（L6-15 讲义原文；repo 例「배우란 게」）
- 命令：**-(으)라고 하다** → **-(으)라 하다**（「들어오라 했는데」）
- 说话动词：**라고 하다** → **라 그러다**（「뭐라 그러나」）→ 只剩 **하다 / 하고**，"心想"也这样说（「여기서 우회전해야지 하고」）

## 采集建议

谈话节目里双方都是当事人，较少需要求证第三方的信息，所以 -다면서요、-다잖아요、-다던데요 这类"转述 + 求证"的形态出现率低；剧本对白（角色之间求证传闻）和新闻评论类素材更容易采到。
